# Rates and Limits

A free, keyless open-data publisher exposing US federal and state tax, payroll, benefits, and wage figures as JSON. Every figure ships bundled with provenance: the exact quoted sentence from the governing government document, byte offsets, sha256-stamped source snapshots, and last-verified dates.

- **Rates and Limits JSON API** — Keyless, unauthenticated REST-style JSON API serving US tax, payroll, benefits, and wage figures with bundled provenance. Includes a self-describing catalog (index.json) and a bulk current-figures endpoint (latest.json). (`https://ratesandlimits.com/api/v1/`)
